# REDRIVER-2-Port-3DS

A 3ds port for REDRIVER 2 :

- This Port is made with REDRIVER 2, so you must have a copy of Driver 2 PS1, and  copy the files in
- SD/3ds/redriver2/Driver2

WARNING :
- This is an alpha port, so some optimisations are still to be done, this game turn at 4-5 fps for the moment
- It tested in an old 3ds, so, for a New 3DS, it may be that there are more FPS
- Its recommended to launch the game with the hb launcher launched with the Rosalina menu (sorry for my English)
